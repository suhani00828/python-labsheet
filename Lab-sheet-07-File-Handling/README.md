# MCA101P-AS10: Python File Handling Programs

This folder contains 30 separate Python 3 programs, one for each task in Lab Sheet-07. Each program includes comments and uses `with` blocks to close files automatically.

## How to use

1. Extract this folder and run a program with Python 3, for example `python 01_write_file.py`.
2. Programs use files beside the `.py` file, so keep those files in the same folder.
3. Text programs generally use `sample.txt`. Number calculations use `numbers.txt` with one number on each line.
4. CSV examples use `students.csv` with the headers `Name,Marks`. Program 21 creates a sample CSV file.
5. For program 20, provide `first.txt` and `second.txt`. For program 30, place source CSVs named `input_1.csv`, `input_2.csv`, etc. beside the program; their headers should match.
