# MCA101P-AS12: CRUD Operations with Python

This folder contains 20 separate Python 3 programs based on Lab Sheet-09. The list and dictionary examples begin with sample in-memory records; those changes last only until the program exits. Text file CRUD stores data in `student_records.txt`. Database examples use SQLite and share `crud_students.sqlite3` beside the scripts; SQLite is included with Python.

## Running the programs

Extract the ZIP, open a terminal in this folder, and run a script such as `python 11_create_students_table.py`. For database tasks, run program 11 first, then use tasks 12-20. Program 20 is a full interactive database CRUD menu. File CRUD task 10 creates its data file on first Add. The programs prompt for values and display success, missing-record, or error messages.

Example: running program 12 and entering `Asha`, `19`, and `85` adds a student. Running program 13 afterward displays that row; program 17 reports the total record count.

The source files were not executed as part of this delivery.
